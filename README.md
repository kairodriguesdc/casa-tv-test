# CASA Test

A throwaway app for your Xiaomi TV that checks four things before we build CASA:

1. **Mic button in CASA:** does the remote's mic button reach CASA?
2. **Voice:** can CASA hear you through the remote?
3. **Mic from anywhere:** can the mic button bring CASA up over Netflix or the home screen?
4. **Smoothness:** does the glass design run smoothly on this TV?

## Install

1. Unzip this folder on your Mac or Windows PC (same home network as the TV).
2. Open Claude Code in the folder and say:

   > Install CASA Test on my TV at 192.168.1.50

   Use your TV's IP address (TV Settings › Network & Internet › Ethernet).
3. Accept the debugging prompt on the TV if it appears.

## Use

The app opens on the TV. Follow each card, then ask Claude Code: **"Read the CASA Test results."**

While the test is installed, the mic button opens CASA Test instead of Google Assistant.

## Remove

Ask Claude Code: **"Clean up CASA Test."** It puts the TV's settings back and uninstalls the app. Free My TV is never touched.
